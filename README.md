# Pharmacovigilance ADR Analytics Dashboard

## Overview
An end-to-end healthcare analytics project focused on analyzing Adverse Drug Reaction (ADR) reports using Python, SQL, and Power BI. The project aims to identify drug safety patterns, severity trends, demographic insights, and key pharmacovigilance metrics through interactive visualizations.Dataset not included due to file size limitations.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- MySQL
- Power BI
- DAX

## Key Features
- Data cleaning and preprocessing of ADR records
- Exploratory Data Analysis (EDA)
- SQL-based drug safety and severity analysis
- Interactive Power BI dashboard with KPIs and filters
- Demographic and drug-specific safety insights

## Dashboard Highlights
- Total ADR Reports
- Serious ADR Percentage
- Top Reported Drugs
- Severity Distribution
- Gender & Age Group Analysis
- Onset Days Analysis
- Drug vs Severity Comparison

## Project Workflow
Dataset → Python Cleaning & EDA → SQL Analysis → Power BI Dashboard → Insights
